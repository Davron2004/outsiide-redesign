Outsiide: before and after the 2.0 redesign

Outsiide is an events app for Ottawa-Gatineau, on the App Store and Google Play. I have been its only developer since mid-2026. Version 2.0 (November 2026) rebuilt every screen of the app.

Left: version 1.4. Right: version 2.0.

Both versions are release builds on the same Android emulator, with the same demo data (made-up posts and people, nothing from real users), captured on October 31, 2026.

Feed

A swipe feed with a heart, share and bell rail became a full-screen reel with For you, Following and Explore, a rail with RSVP, Save and Share, and a floating tab bar with a Map button.

Post details

Details used to be a separate long page. Now a sheet opens over the paused post, with a When / Where / Price / Age grid and the event chat.

Post details, full screen

The sheet drags up into a full screen with About, the venue map, Directions and Copy address.

RSVP

Native alerts became an RSVP sheet with price, age limit and spots left.

Map

The Live tab showed only posts happening right now. The map is now a mode of Discover that shows the feed's own results, with type pins, clusters and one shared radius (5 / 10 / 25 / 50 km).

Search

The Search tab became a full search screen with the active filter as a chip and grouped Posts and Tags results.

Filters

The filter dialog with checkboxes became a Filters sheet with radius, date, type and price, and a live “Show 12 posts” count.

Plans

The RSVP tab (RSVP, Liked, Saved) became Plans: Going, Saved and Past, with a week strip and a month view.

Inbox

The notification list behind the bell became an Inbox tab with a badge, Chats and Updates.

Ticket

The QR card became a ticket with date, time, venue, an entry code and the holder's name.

Door scanner (host)

The host's scanner got a manual code entry, a torch and full-screen results: Admit, Already in, Not valid, with a running count.

Review before publishing (host)

1.4 had no review step. 2.0 shows the post as it will appear in the feed, with guides for the areas the buttons cover.

Create post (host)

One long form became five steps, starting with “What is it?”.

Experience page

Places you can visit any time no longer show an RSVP button; they show opening hours and an open or closed status.

Sign in

The sign-in screen, redrawn.

Settings

Account settings, redrawn and reorganized.

Event chat (new in 2.0)

A chat room per event, with a pinned host announcement, replies and a HOST badge. Messages are screened by a word filter and OpenAI moderation.

Large text (200%)

The same screen with the phone's font size at 200%.

Light theme

1.4 was dark only. 2.0 follows the phone's light or dark setting.
